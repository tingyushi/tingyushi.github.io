## **Autonomous Indoor Navigation Robot System Development**
  - Develop both open-loop and closed-loop control systems enabling a robot to navigate through predefined waypoints using AprilTag-based localization
  - Implement EKF-SLAM for simultaneous localization and mapping, and integrated path planning algorithms optimizing for minimum travel distance and maximum obstacle avoidance
  - Combine control, localization, and planning modules into a functional autonomous Roomba-like system, achieving robust indoor navigation and target tracking.
  - [Github Link](https://github.com/tingyushi/Robotics)

## **Analysis Study on the Sentiment Classification Model**
  - Conducted a comprehensive error analysis of a RoBERTa-based sentiment classification model fine-tuned on TweetEval, identifying key failure modes including negation handling, typos, irony, and social biases
  - Designed adversarial test cases and dataset perturbations (e.g., typo injection, ironic sentence generation using GPT-4, and demographic substitutions) to stress test the model and quantify performance degradation and fairness issues
  - Proposed concrete mitigation strategies, including data augmentation, negation-aware tokenization, irony detection integration, and test-time adaptation, to enhance robustness and fairness in sentiment classification
  - [Report](/files/Sentiment_Classification_Model_Analysis_Study.pdf)

## **Convex Optimization with Image Denoising**
  - Formulated the image denoising problem as a convex optimization task, deriving primal, dual, and KKT conditions
  - Implemented and compared four denoising methods: Tikhonov Regularization, Total Variation Denoising, Patch Group–based Non-Local Self-Similarity with Sparse Representation, and DnCNN
  - Evaluated denoising performance on multiple natural images under varying Gaussian noise levels using PSNR and SSIM metrics, demonstrating the superior detail preservation of DnCNN
  - Analyzed the strengths, limitations, and computational complexities of traditional convex optimization methods versus deep learning–based approaches
  - [Report](/files/Convex_Optimization_Image_Denoising.pdf)


## **Digital Twin Forest Software Application**
  - Conducted literature review on digital twin technologies for environmental and ecological applications
  - Developed a parametric model to create a virtual representation of a real forest (Turkey Point, Ontario, Canada) using data from the Remote Sensing Lab
  - Implemented forest data visualization and real-time synchronization between collected forest data and the virtual forest model
  - Optimized Unity Terrain Tool functionality to enable dynamic tree planting and improve modeling efficiency
  - Contributed to the field of environmental science research, helping predict and mitigate the impacts of climate change, as well as manage natural resources more efficiently
  - [Github Link](https://github.com/tingyushi/DTForest-Doc/tree/main) and [Demo Video](https://www.youtube.com/watch?app=desktop&v=r75mvbEOSkQ)
